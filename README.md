## Introduction

This portfolio contains five algorithmic problems completed as part of the 3rd Semester Computer Science and Engineering activity. The solutions are implemented in C++ and demonstrate sorting, searching, array processing, and greedy algorithm techniques.

## Problems and Analysis

### 1. Mini-Max Sum

**Approach:**  
Read the five numbers, sort them, and calculate the sum of the smallest four numbers and the largest four numbers.

**Time Complexity:** O(N log N)  
**Auxiliary Space:** O(N)

**Alternative:** Track the minimum, maximum, and total sum without sorting.

---

### 2. Birthday Cake Candles

**Approach:**  
Find the maximum candle height and count how many candles have that height.

**Time Complexity:** O(N)  
**Auxiliary Space:** O(N)

**Alternative:** Track the maximum height and count while reading the values.

---

### 3. Insertion Sort – Part 1

**Approach:**  
Store the last element and shift larger elements one position to the right until the correct position for the last element is found.

**Time Complexity:** O(N)  
**Auxiliary Space:** O(N)

**Alternative:** Use a standard insertion sort implementation for the complete array.

---

### 4. Binary Search

**Approach:**  
Use two pointers, left and right, to repeatedly check the middle element of a sorted array and reduce the search range by half.

**Time Complexity:** O(log N)  
**Auxiliary Space:** O(N)

**Alternative:** A linear search can be used, but it takes O(N) time.

---

### 5. Mark and Toys

**Approach:**  
Sort the toy prices and purchase the cheapest toys while the total cost remains within the available budget.

**Time Complexity:** O(N log N)  
**Auxiliary Space:** O(N)

**Alternative:** Other data structures could be used to select affordable prices, but sorting provides a simple and efficient solution.
